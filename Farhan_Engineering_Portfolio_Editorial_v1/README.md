# Farhan Ali - Engineering Portfolio

A personalised version of the **Editorial by HTML5 UP** template. Hosted as a static site: no build tools, frameworks or paid hosting required.

## What is included

- Dark theme by default, with a sidebar toggle. The chosen theme is saved on the visitor's device when browser storage is available.
- Responsive navigation with expandable project categories.
- A featured-project homepage and four starter case-study pages based on the current CV.
- Direct links to Farhan's GitHub project repositories, Medium, LinkedIn and email.
- Accessible stylised technical diagrams instead of unrelated stock photographs. **These are illustrations, not evidence or photographs of the actual hardware.**
- Copyright and design credit retained for HTML5 UP.

## Publish through GitHub Pages

1. Sign into GitHub and create a new **public** repository, for example `engineering-portfolio`.
2. Upload **the contents** of this ZIP to the repository root, including `index.html`, `projects/` and `assets/`.
3. In repository **Settings -> Pages**, choose **Deploy from a branch**, then **main** and **/(root)**. Save.
4. Open `https://farhan10904.github.io/engineering-portfolio/` once GitHub Pages has deployed. The final URL depends on the repository name.
5. Test the sidebar and theme switch on desktop and mobile.

## Editing

- `index.html` - introduction, featured project cards, archive, skills, writing and contact content.
- `projects/gimbal.html`, `robot.html`, `brayton.html`, `radar.html` - individual starter case studies.
- `assets/css/portfolio.css` - all custom appearance rules, including both themes.
- `assets/js/theme.js` - persistent theme toggle.
- `assets/css/main.css` and `assets/js/main.js` - original HTML5 UP Editorial behaviour, adapted only to remove font-file dependencies.

**Before public promotion:** replace the schematic-style illustrations with actual project photos, outputs and engineering figures; check facts and performance numbers against original files; add full reports and article URLs once published.

**Privacy:** `index.html` contains the email address from the supplied CV as a public contact method. Remove or replace the `mailto:` link before publishing if you do not want it public.
